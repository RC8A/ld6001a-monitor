# Подготовка публикации

Планируемый репозиторий: `RC8A/ld6001a-monitor`. Видимость: **private**. Первый релиз: **v1.0.0**, первоначально **draft**.

Локально подготовлены исходники, лицензия, README, журнал изменений, CI, правила приёма изменений и ZIP релиза. Ничего не отправляется на GitHub обычной сборкой или упаковкой.

## После восстановления доступа GitHub CLI

Выполните `gh auth login`, затем проверьте `gh auth status`. Вход выполняет владелец аккаунта; токены не сохраняются в репозитории.

Из корня проекта:

```powershell
powershell.exe -NoProfile -File .\scripts\Publish-Private.ps1 -Repository RC8A/ld6001a-monitor
```

Скрипт требует чистый Git, готовый ZIP и действующую авторизацию, создаёт только приватный репозиторий, отправляет main и создаёт черновик релиза. Если репозиторий уже существует, его видимость должна быть private. Создание репозитория и отправка файлов происходят только при явном запуске этого скрипта.

После отправки проверьте Actions, состав релиза и доступ участников. Черновик не публикуется автоматически. Публичную видимость можно менять только отдельным решением владельца.

## Версионирование

- `version.txt` — версия релиза, начиная с 1.0.0.
- `Source/.build-number` — локальный счётчик успешных сборок; в Git не входит.
- EXE содержит версию файла 1.0.0.N и информационную версию 1.0.0+build.N.
- Перед следующим исправляющим релизом: `scripts/Bump-Version.ps1 -Part Patch`, затем сборка, проверки, обновление CHANGELOG и пакет.
- CI задаёт номер сборки через номер запуска GitHub Actions.

В релиз не включаются data, logs, программы производителя и Source/Archive. Снимки тестов остаются артефактами CI, а не личными данными из действующего соединения с датчиком.
