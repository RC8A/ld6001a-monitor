# LD6001A Monitor 1.0.0

Первый подготовленный релиз независимой тестовой программы для HLK-LD6001A-60G.

**Автор:** Dmitry Popov. **Лицензия:** PolyForm Noncommercial 1.0.0.

Windows 10 x64, .NET Framework 4.7.2 или новее. Распакуйте ZIP и запустите `LD6001A Monitor.exe`. Программа не требует установки. Настройки и журналы создаются рядом с EXE.

Поддерживаются DEBUG 0/3, карта и следы, зеркала, зона мышью, таблица параметров, ACK и проверка чтением, индикаторы START/STOP. Подключение только читает параметры; правки применяются через 1 с.

В ZIP нет личных настроек и журналов. SHA-256 находится в соседнем файле. EXE не подписан цифровой подписью. Программы и прошивки производителя не входят в релиз.

Этот релиз предназначен для начала приватного тестирования. Проверки без оборудования не заменяют проверку на конкретном датчике.

- Русский и английский интерфейсы с сохранением выбора языка.
